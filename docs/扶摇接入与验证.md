# 扶摇资讯接入与验证

版本v1.2，2026-10-31（北京时间）。只依据第三题Markdown要求实现，不制作可选视频。

## 已接入能力

- 个股分时新闻：GET /api/news/stock/timeline-list，完整A股代码、首屏最多20条。
- A股快讯栏目：GET /api/news/flash/list，固定tag_id=21103、首屏seq=0。
- 所有请求固定发往https://fuyao.aicubes.cn，使用服务端FUYAO_API_KEY；不跟随重定向、不将密钥传给前端。没有创建或重置平台密钥。
- HTTP成功且业务code=0才接受；权限、上游错误、超时、结构错误、危险链接和额度错误均明确显示。查询失败不写入工作区。
- 同一查询60秒缓存，保留原抓取时间；每实例每客户端6次/分钟、60次/天，实例200次/天、并发2次，属于内存保护，不是账户级硬上限。

官方文档：[个股分时新闻](https://fuyao.aicubes.cn/docs/api-reference/news-stock-timeline/)、[快讯列表](https://fuyao.aicubes.cn/docs/api-reference/news-flash/)、[接口总览](https://fuyao.aicubes.cn/docs/api-reference/overview/)。

没有调用仅限同花顺AI客户端的资讯事件库，也没有把公告“解读”当作公告原文。iFinD未接入；本题优先数据源已选择扶摇。

## 实际操作主链路

来源与数据 / 查询扶摇资讯 → 选择个股或快讯 → 查询 → 核对来源链接和摘要 → 选为待分析材料 → AI或规则分析 → 人工核对事件归属、主张分类、金额单位/范围与标的关系 → 确认保存 → 时间线、更新记录与证据抽屉。

查询结果本身不改变结论；真实资料不能混入构造事件。已存在的同原文会拦截，同一扶摇内容ID保留相同来源组。摘要可能被上游截断，不能据此补造全文、发生时间或未披露内容。

## 时间与来源字段

材料新增capturedAt，表示服务端实际完成本次成功取数的时间；ingestedAt仍表示人工确认保存时刻。两者分开保留，缓存命中不会更新capturedAt。publishedAt来自publish_time_ms或create_time_ms；快讯updatedAt来自update_time_ms。未返回发生时间或更新时间就保持缺失。原有导出文件可兼容，缺少抓取时间时显示未提供。

provenance保存提供商、接口、请求ID、内容ID和相应原始标题/摘要/时间字段；原始来源链接保留。证据抽屉显示该来源元数据。扶摇接口返回并不表示新闻事实已获独立核验；新闻摘要不自动升级为公告或高权重。

复核页可添加/更新同名关联标的、角色及原文逐字关系依据，绑定本次材料；新建事件可正常维护关系。关系是人工确认内容，不是模型保证。旧内置关系保持其已有人工简述，不伪造逐字核验。

## 验证

- 真实API经应用适配器查询个股与快讯均HTTP200、业务成功，每类20条；时间、来源链接与请求ID可检查。[脱敏元数据](./evidence/fuyao-live-test.json)。
- 原有68条加资讯接口14条、时间和关系3条，共85条测试通过，构建和Worker ESM校验通过。接口边界测试使用mock，与真实调用记录分开。
- 本地Chrome实操：查询300033.SZ → 选择摘要 → 规则分析 → 人工删除不完整评论、规范金额和单位/范围 → 新建事件 → 添加同花顺标的关系 → 保存 → 关系依据跳转到材料；抓取时间00:03、录入00:04分别显示，未知发生/更新时间为空。[本地时间截图](./evidence/fuyao-local-times.jpg)。
- 线上部署与复测结果在完成后补充，不以本地成功替代Worker连通性证明。

## 数据与许可边界

使用平台公开查询能力；仅按需呈现接口提供的摘要与原链接，不批量采集全文或形成公开下载的数据集，不把研报摘要当作可再分发全文。代码仓库不提交取回的新闻响应批量文件；本轮测试记录只保存脱敏接口元数据。用户材料存在当前浏览器，导出前应核对其授权范围。未独立取得可无限再分发/商业转售许可。

## 本地与线上配置

线上FUYAO_API_KEY使用Sites Secret，现有MiniMax设置保持。提交包不带密钥，解压后可在app/.env配置自己的合法密钥；不配置时资讯查询明确返回503，手工材料与规则分析仍可操作。环境变量示例见app/.env.example。

不实现视频、交易、持仓、新闻全文爬虫、自动订阅、后台推送或共享数据库；这些不是第三题要求的必交能力。
