## 构造样例

- **澄明能源 / 海岬储能项目**：公司、合作方、项目、金额和所有来源均为虚构，无真实证券代码。5 份内置材料分别覆盖传闻、同源转载、公司框架公告、合作方金额冲突及研究观点。
- **临川医疗 / 一期采购项目**：完全虚构。2 份材料覆盖传闻、公司否认和明确有效期结束。
- **录入面板中的三份快捷材料**：完全虚构的金额更正、业绩否认和同公司其他项目。只有实际提交后才加入工作区，不算在默认 11 份材料中。

构造案例用于验证处理逻辑，不能证明真实资讯识别准确率或真实企业存在该事项。未伪造真实公司公告截图、金融接口响应或真实研报。

## 扶摇与 iFinD 状态

题目入口为 [扶摇文档](https://fuyao.aicubes.cn/docs/) 和 [iFinD MCP](https://mcp.51ifind.com/?syncCookieTimes=1)。本次工具清单没有相应专用调用工具；网页读取未得到有效文档内容（不可访问/超时）。因此未取得能力、权限、数据字段、许可与接口成功调用的证据。不能据此宣称服务本身不可用。

当前可实际使用的输入路径是内置公开资料摘录、构造资料及用户手工输入；没有实时资讯 API。以后接入时需验证来源许可、原文与四类时间字段、来源之间的引用关系，并保留接口失败状态。

## 可再分发与隐私

提交包只包含必要公开摘录、原链接和虚构测试数据，无 API Key、客户资料、真实持仓或受限研报全文。用户新输入保存于浏览器；导出 JSON 含原文，分享前需自行核对。默认测试导出的复现工作区仅含上述公开摘录和构造材料。
