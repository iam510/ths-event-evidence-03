## 建议补齐顺序

1. **标的关系闭环**：新增/编辑关系，选择公司或标的、关联角色、依据主张/材料；保存后可追溯，原依据更新或失效时提示复核。至少让新事件能走完题目描述的完整任务。
2. **时间语义闭环**：分别保存抓取时间（确有抓取时）、系统录入时间、发生/披露/源材料更新时间；未抓取就显示未提供，保留导入时的原始抓取时间。无需为满足字段而伪造抓取行为。
3. **模型评估增强**：加入真实合法公开材料的少量人工标注案例，覆盖事实/观点/推测/传闻、同公司不同项目、否认与更正、缺日期、无来源、指令注入、失败保持原结论，记录逐项通过和人工修正，不仅统计请求成功。
4. **真实数据源增强**：验证扶摇或iFinD当前账号可调用、许可与字段，选择能支撑事件证据的接口。数据平台接入不能由行情快照替代原文证据。
5. **可选展示**：录制60–180秒主任务演示。账号、云同步、多用户数据库、推送和完整爬虫不是本题明确必交项，不应优先于前两项。
