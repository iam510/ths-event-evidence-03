## 手动复测步骤

先启动 `npm run dev`。按 README 的2分钟步骤操作；重置前导出备份。真实历史案例检查CMA原方案阻止与重构方案获批的明确版本关系，不把监管批准单独当作交割证据。核对原文页的四类时间，未知字段应保持未提供。

再次录入同份材料应被阻止。选择旧目标以外的主张或不同范围，应拒绝更正。更改来源元信息的用户输入不得保留内置核验高权重；无来源链接的真实材料应低权重。收益承诺或买卖建议不能保存为事实结论。
